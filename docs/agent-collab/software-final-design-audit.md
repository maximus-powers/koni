## 2026-07-14 final independent verdict

Status: `complete` — Software design audit finished; Research remained read-only and unchanged.

### Design conclusion

The Software 0.4 default should retain **Evidence-Guided Vertical Delivery** as its governing
paradigm. It is the best synthesis for agent execution in this harness:

- phase-gated or role-gated delivery creates stale handoffs and rewards agents for producing
  artifacts rather than one observable outcome;
- universal red-green TDD manufactures failures for mechanical or legacy-preservation work;
- file-, layer-, persona-, test-, or ontology-node microtickets increase context loss and review
  overhead without adding an independent authority or evidence boundary;
- unconstrained vertical slicing is lean but under-specifies causal evidence, proof currentness,
  risk, and recovery; and
- the selected model keeps the vertical claim while making only material contracts, risks,
  decisions, causal defects, proofs, and delivery closure compile into work.

This agrees with Updog's strongest patterns: one approval claim and evidence packet, the cheapest
trustworthy proof layer, a higher layer only for a distinct remaining gap, tests and production in
the same vertical ticket, bounded correction, and no role/file taxonomy splitting. It deliberately
does not copy Updog's instruction sprawl or universal handoffs. It also shares Research's
evidence/currentness philosophy without importing metrics, ablations, assets, or conclusion
ceremony into Software.

The profile addresses common agent failure modes well: it makes repository facts discoverable,
turns prompt claims into typed graph or receipt gates where feasible, limits authority by exact
paths and targets, separates independent semantic review from implementation, prevents silent
risk acceptance, and avoids duplicate Verifier/Integrator hops. Semantic judgments that cannot be
made mechanical—proof relevance, nonredundancy, root-cause quality, cohesive slice size—remain
explicit Reviewer duties rather than being disguised as compiler guarantees.

### Resolved findings in current Software bytes

  now structural. The new negative fixture prevents duplicate preparation fanout. A malformed
