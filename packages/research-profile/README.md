# `@koni/research-profile`

This Pi package carries Koni's graph-first academic research profile: scientific node and edge
types, rules, operations, workflows, run types, personas, agent instructions, and skills.

Its extension is a non-authoritative registrar. `@koni/core` verifies the complete bundle before
materialization and owns every compiler, workflow, state, and Git effect.

Research is optional. Install it with `pi install npm:@koni/research-profile` when needed, then
initialize with explicit `koni init research`. The profile stores each reciprocal scientific fact
once and exposes inverse traversal through edge policy, avoiding redundant circular claim/experiment
relationships. Research run types and skills remain part of this broad profile package. Globally
installed packages remain passive outside initialized repositories: they do not create a run,
authority, or provider attempt.

> Release transition (2026-07-18): Research `1.1.0` publishes the reviewed Pi-native defaults and an
> authenticated, preview-required retirement from the exact official `1.0.11` bundle. Project edits
> remain overlay-owned. The release never replaces a customized `.koni` tree wholesale.
